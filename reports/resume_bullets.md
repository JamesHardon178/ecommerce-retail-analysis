## 版本 A · 数据分析岗（推荐，3 条版）

**电商销售增长与客户复购分析平台**（个人项目，Python / SQL / Streamlit）

- 基于 UCI Online Retail II 真实交易流水（106.7 万行、25 个月），使用 pandas 完成 7 段互斥分段清洗
  （去重 3.4 万行、拆分退货 1.9 万行），保证各分段行数加总与原始数据 100% 闭环；
  构建 SQLite 分析库并编写 **9 条含窗口函数（LAG / RANK / NTILE / ROW_NUMBER）的专题 SQL**，
  与 Pandas 双路径交叉验证 16 项指标全部一致，并用 9 个 pytest 用例锁定指标口径。
- 围绕收入趋势、RFM 客户分层、Cohort 留存、退货归因、市场/商品集中度 5 个业务问题完成分析：
  量化出**复购率 72.4%、前 10% 客户贡献 63.9% 收入、M+1 留存 20.3%、退货率 7.1%**等关键结论，
  并识别出单笔 £168,470 退货占全期退款 11.5%、TOP4 商品收入与退款完全对冲（虚假热销）等隐藏问题。
- 开发 Streamlit 5 页交互看板（Plotly），所有图表标注时间范围与统计口径，
  主动标记数据截断月（2011-12 仅 8 天）与 Cohort 左/右截断边界，避免将数据缺陷误读为业务下滑。

## 面试追问弹药库（背下来）

| 可能的问题 | 真实答案 |
|---|---|
| 净收入怎么算？ | 销售收入 £20,476,260（数量>0 且单价>0）− 退货 £1,462,424 = 净收入 £19,013,836；客单价 £474.43 |
| 复购率 72% 是不是太高？ | 这是 B2B 批发数据，客户本身高频下单；因此我同时用"前 10% 客户贡献 63.9% 收入"来刻画客户结构，单看复购率会高估忠诚度 |
| 数据质量最大的坑？ | 双 sheet 在 2010-12 有时间重叠，合并后出现 34,335 行完全重复；2011-12 数据止于 12-09 只有 8 天，直接做同比会得出"-70% 崩盘"的错误结论 |
| 退货分析最重要的发现？ | 退货率 7.14% 看起来正常，但单笔 £168,470 就占 11.5%；剔除后主要"退货"是 AMAZONFEE 等费用冲销——问题不在货，在少数大单的履约/结算 |
| 商品集中度？ | 4,719 个 SKU，HHI 仅 17.4（<1500 为低集中度），TOP10 只占 8%，无单品依赖风险，但也缺爆款；TOP4 商品收入 £168,470 与退款完全对冲，评估必须看净额 |
| 如果继续做会做什么？ | ① 大额订单履约预警（单笔 >£50K 上报）② EIRE 海外下滑专项归因 ③ 首购后 30 天未复购的自动唤醒策略并做 A/B 验证 |
